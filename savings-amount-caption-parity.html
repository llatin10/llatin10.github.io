Savings amount screen — caption text differs between Android and iOS

Prepared for Product · Android release 4.7.0 vs iOS 4.7.0 · Savings → deposit amount entry · 2026-10-07

The caption under the amount on the savings deposit screens (daily, monthly, yearly) shows different text on Android and iOS, and it behaves differently once the user starts typing. We need Product to confirm the intended behavior so we can file the right bugs.

Screenshots (Android left, iOS right)

Different test accounts were used (Android balance ₪434,479.39, iOS ₪60,000), so the plan type on each device was not identical in every shot.

Plan type per screenshot is inferred from the code, not confirmed on the device. The one-time deposit with an empty amount is most likely the daily plan; the one with ₪100 typed is most likely the monthly plan.

Why they differ (from the code)

  • Android: the first message depends on the plan (monthly shows the "initial deposit" text, fixed yearly shows the maximum). As soon as the user types, the caption switches to the minimum-amount message for every plan.
  • iOS: the caption is whatever the plan's flow passes in and it never changes while typing. Daily and floating yearly pass nothing, monthly passes the "initial deposit" text, fixed yearly passes the maximum.
  • An existing open iOS ticket, OZ-134109 (finding #4), already notes that iOS does not show the minimum amount on the one-time deposit screen while Android does.
  • The Figma frame for "Create Fixed Yearly Saving" amount entry (title "סכום הפקדה") has an empty caption, so it does not settle the question.

Questions for Product

1. Should the amount screen show a caption at all, and should it differ by plan type (daily / monthly / yearly fixed / yearly floating)?
2. Should the caption stay fixed while the user types (iOS today), or switch to the minimum-amount message once they type (Android today)?
3. For daily and floating yearly: show the minimum-amount message (Android) or nothing (iOS)?
4. For fixed yearly: show the maximum ("אפשר להפקיד עד …") throughout, or the minimum once the user types?
5. Is there a Figma frame for the "הפקדה לשנה" / "הפקדה חד פעמית" amount screens that defines this? If so, please share the link.
